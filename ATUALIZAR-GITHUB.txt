IMPACTO — PREMIUM 4.2 — CORREÇÃO DO FLUXO DE COMPARTILHAMENTO

Este pacote contém 18 arquivos, todos na mesma pasta, como a versão 4.1.

ATUALIZAR PELO CELULAR
1. Guarde um backup .JSON no aplicativo atual.
2. Baixe este ZIP e escolha Extrair em Meus Arquivos > Downloads.
3. No GitHub, abra a raiz do repositório Impacto-Technological e use Upload files.
4. Entre na nova pasta extraída e selecione TODOS os 18 arquivos. Não envie o ZIP fechado.
5. Confirme em Commit changes e aguarde a publicação do GitHub Pages.
6. Abra o app conectado à internet; feche todas as janelas do app e abra novamente.
   O cabeçalho deve mostrar PREMIUM 4.2.

Mantenha o mesmo endereço do site. Não limpe o armazenamento do navegador nem
reinstale o app para atualizar. Não é necessário apagar arquivos do repositório.

O QUE FOI AJUSTADO
O compartilhamento normal de PDF mantém o mesmo gerador e a chamada ao menu nativo.
Ao gerar ZIP, o aplicativo identifica se o navegador aceita compartilhar esse formato.
- Se aceitar: mostra Compartilhar ZIP.
- Se não aceitar: mostra Salvar ZIP no aparelho e os passos para enviar por Arquivos.
Não há download automático nem tentativa de disfarçar o formato do ZIP.

COMO ENVIAR O ZIP NO CHROME/ANDROID
A implementação atual do Chrome para Android permite PDF, mas não inclui ZIP
na lista de formatos aceitos pelo menu de compartilhamento da página.
O aplicativo web não consegue habilitar essa permissão por conta própria.
1. No app, gere o ZIP e toque em Salvar ZIP no aparelho.
2. Abra Meus Arquivos ou Arquivos > Downloads.
3. Segure o ZIP e escolha Compartilhar > WhatsApp.
Também é possível abrir a conversa no WhatsApp e usar Anexar > Documento.
No iPhone, quando o navegador não aceitar ZIP diretamente, use Arquivos > Downloads.

COMPARTILHAR SOMENTE O PDF DO PACOTE
O ZIP já contém um PDF. O app mantém esse PDF pronto e permite compartilhá-lo
pelo botão Compartilhar somente o PDF, se o navegador aceitar.
Esse envio inclui apenas o relatório: não envia o backup editável e os anexos
originais como arquivos separados. O ZIP completo continua disponível para salvar.

SE O MENU DO APARELHO NÃO RESPONDER
O app informa a espera e mantém Salvar e Fechar disponíveis.
Uma solicitação nativa pendente não bloqueia a navegação do aplicativo.
Enquanto o sistema não concluir a solicitação, novas chamadas de compartilhamento
ficam desativadas para evitar duas solicitações simultâneas.
O app não confirma entrega ao destinatário e nunca envia a contatos automaticamente.

DADOS E OFFLINE
O banco campo_nr_v2 e os backups existentes foram preservados.
Abra online uma vez após atualizar para carregar o novo cache. Depois, PDF e ZIP
continuam sendo gerados no aparelho. Guarde um backup externo ao fim da visita.
Arquivos grandes continuam sujeitos à memória e aos limites do dispositivo.

O PDF, o ZIP e o backup incluem todos os itens, mesmo com filtros ativos, inclusive
os custos de fabricação registrados. O backup mantém as formas e fotos de fundo.

TESTES

conclui foram simulados em Chromium com tela de celular. PDF e ZIP reais foram
gerados offline. Não foi enviado arquivo para WhatsApp real.
