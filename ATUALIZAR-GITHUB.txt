IMPACTO — PREMIUM 4.1 — ENVIO PELO CELULAR

Este pacote contém 18 arquivos, TODOS NA MESMA PASTA. Não há pastas vendor/assets.
As funções da versão Premium 4 foram preservadas; mudou a organização dos arquivos
para permitir o envio pelo seletor de arquivos do celular.

COMO ATUALIZAR
1. Guarde um backup .JSON no aplicativo atual antes de atualizar.
2. No GitHub, cancele/volte da seleção anterior sem confirmar Commit changes.
3. Baixe este novo ZIP. Em Meus Arquivos > Downloads, toque nele e escolha Extrair.
4. No GitHub, abra o repositório Impacto-Technological na raiz, aba Code.
5. Use Upload files > choose your files. Abra a nova pasta extraída e selecione
   TODOS os 18 arquivos de dentro dela. O arquivo ZIP fechado não deve ser enviado.
6. Confirme em Commit changes. Aguarde a publicação do GitHub Pages concluir.
7. Abra o app conectado à internet. Feche todas as janelas do app e abra novamente.
   O cabeçalho deve mostrar PREMIUM 4.1.

Não é necessário apagar arquivos antigos ou pastas anteriores do repositório.
Os arquivos de mesmo nome serão substituídos pelo novo envio. Não apague o banco
local, não limpe os dados do navegador e não desinstale o app para atualizar.
Use o mesmo endereço de sempre para continuar acessando seus levantamentos.

PDF E WHATSAPP
Exportar > Gerar PDF e compartilhar > aguardar "Arquivo pronto" > Compartilhar.
No menu do aparelho, escolha WhatsApp, o destinatário e confirme o envio.
O PDF também pode ser visualizado ou baixado. Se o menu não aceitar o arquivo,
baixe o documento e use WhatsApp > Anexar > Documento.
O segundo toque em Compartilhar é necessário após preparar o arquivo.

ZIP COMPLETO
Inclui PDF, CSV, imagens por área/item e backup JSON com croquis editáveis.
Todos os itens são exportados, mesmo com filtros ativos. Os custos registrados
para fabricação também são incluídos. Use PDF em qualidade equilibrada para
reduzir o tamanho dos arquivos. O envio real depende do menu do seu aparelho.

OFFLINE E BACKUP
Abra o app online após atualizar para que o novo pacote seja armazenado.
Depois, PDF e ZIP são gerados localmente. Mantenha o app aberto até concluir.
Exporte um backup .JSON ao final de cada visita. Os dados ficam neste navegador;
não há sincronização automática entre dispositivos.
Backups válidos das versões 2 e 3 continuam aceitos.

CROQUI
Zoom +/−, pinça, mover e ajustar à tela. Cotas positivas em milímetros, formas,
texto, cores, espessuras, grade, desfazer/refazer e edição sobre foto.
As coordenadas e cotas permanecem iguais ao ampliar ou reduzir a visualização.

O HTML Levantamento_Campo_NR12_NR33_NR35.html é uma edição autocontida adicional.
O site/PWA utiliza index.html. Prefira o site HTTPS ao arquivo local no celular.
Consulte AUDITORIA-PREMIUM-4.md para testes e limitações.
